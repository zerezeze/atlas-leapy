# Onboarding de Clientes Startup

O plano Startup tem foco em volume e agilidade, adotando um formato _Tech Touch_ (autoatendimento com intervenções pontuais).

## Prazos e SLAs

- **Acesso à Plataforma:** Imediato após a confirmação do pagamento via cartão de crédito.
- **Duração Estimada:** O cliente deve ser capaz de realizar o setup completo sozinho em até 2 horas úteis utilizando o assistente guiado in-app.

## Processo de Ativação

1. Cliente cria conta via link público.
2. O sistema dispara e-mails automatizados com tutoriais curtos (Gotejamento/Drip Campaign por 7 dias).
3. O time de CS só intervém se o "Health Score" despencar nos primeiros 14 dias (indicando abandono do onboarding).
