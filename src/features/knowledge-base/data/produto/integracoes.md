# Integrações Nativas

A plataforma Leapy se integra de maneira nativa (Plug and Play) com as seguintes ferramentas do mercado:

## CRMs

- **Salesforce:** Sincronização bidirecional de contatos e oportunidades (Exclusivo plano Enterprise).
- **HubSpot:** Sincronização de leads e envio de eventos de automação (Disponível em todos os planos).

## Comunicação e Produtividade

- **Slack:** Envio de alertas e notificações para canais específicos ou DMs de usuários.
- **Microsoft Teams:** Envio de alertas automáticos.
- **Google Workspace (Drive):** Exportação automática de relatórios gerados.

## API Pública

Clientes que precisam conectar sistemas legados podem utilizar nossa API REST (documentação em developer.leapy.io). O rate limit da API é de 100 requisições por minuto no plano Startup e 500 no plano Enterprise.
