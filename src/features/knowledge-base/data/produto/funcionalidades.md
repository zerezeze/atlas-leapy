# Funcionalidades Principais da Plataforma Leapy

A plataforma Leapy possui três módulos principais que os clientes mais utilizam no dia a dia:

## 1. Módulo de Automação de Tarefas

Permite que o usuário crie fluxos de trabalho do tipo "Se X acontecer, faça Y". É altamente personalizável e não requer conhecimento em programação (No-Code). Limite de 50 automações ativas no plano Startup e ilimitadas no plano Enterprise.

## 2. Dashboard de Analytics

Gráficos em tempo real sobre a produtividade da equipe do cliente. O dashboard é atualizado a cada 5 minutos. Relatórios customizados em PDF/Excel só podem ser extraídos por clientes de planos superiores.

## 3. Gestão de Permissões

Permite convidar membros para o _Workspace_. Existem 3 perfis:

- Administrador (Acesso total)
- Membro (Pode editar registros, mas não pode alterar cobranças)
- Visualizador (Acesso somente leitura)
